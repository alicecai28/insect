Methodology

How Monte Carlo works here

The Monte Carlo method replaces a single, fragile point estimate with a distribution of possible outcomes — sampled thousands of times from probability models fitted to the observed data. This is particularly valuable in ecology, where counts are noisy, sampling is incomplete, and uncertainty is the rule rather than the exception.

The Core Idea
From one observation to ten thousand possibilities
When the paper reports "5,567 Diptera at ground level," that number is a single two-week snapshot — one realisation of a random process. How confident can we be that it reflects the true average?

Monte Carlo answers this by asking: if the true mean really were 5,567, what range of counts would we expect to see across many repeated surveys? We draw 10,000 random samples from that distribution, and the spread of those samples becomes our uncertainty estimate.

Crucially, we can then propagate that uncertainty through every downstream calculation — logging impact scores, species loss estimates, robustness checks — so our conclusions carry honest error bounds rather than false precision.
Why Not Standard Statistics?
When the maths gets complicated, simulate
Classical statistics works beautifully for simple cases. But this study involves non-normal count data, five interdependent height levels, eight insect families, three logging scenarios, and three seasonality assumptions — all combined into weighted biodiversity impact scores.

Deriving exact analytical confidence intervals for such a layered calculation would require complex, assumption-heavy algebra. Monte Carlo sidesteps this entirely: run the full calculation 10,000 times with slightly different inputs each time, and read the uncertainty straight off the resulting distribution.
Specifically, Monte Carlo lets us:
  • Quantify sampling uncertainty — how much does a two-week window miss?
  • Test robustness — do conclusions survive seasonal variation?
  • Model counterfactuals — what if logging removed certain heights?
  • Extrapolate honestly — species accumulation curves with calibrated CIs
  • Combine uncertainty sources — trap bias, seasonal noise, and sampling all at once
The Four Modules
01
Poisson Abundance Simulation
Turning counts into distributions
Insect counts are Poisson-distributed — the natural model for rare events in continuous time. The observed count at each height becomes the distribution's λ (rate) parameter.

Drawing N=10,000 samples from Poisson(λ) for each of the 5 heights × 8 orders gives 400,000 simulated counts. The 2.5th and 97.5th percentiles of each set become the 95% confidence interval.

If two heights' CIs don't overlap, the difference is statistically robust — not explained by sampling noise alone.
# For each order at each height: λ = observed_count # e.g. 5567 Diptera at 0m samples = rng.poisson(lam=λ, size=10_000) ci_lo = percentile(samples, 2.5) ci_hi = percentile(samples, 97.5)
02
Species Richness Extrapolation
Estimating the unseen
How many species exist but were never caught? We model each trap height as a random sample from the total species pool, with detection probability derived from observed richness relative to the total.

Across 10,000 runs, we randomly combine subsets of heights and count unique species detected. The resulting species accumulation curve is then fitted to a negative exponential saturation function S(k) = Smax(1 − e−κk), whose asymptote estimates true total richness.
# Saturation curve fit: S(k) = S_max × (1 − exp(−κ × k)) # where k = number of trap heights # S_max estimated by scipy.curve_fit S_max ≈ 858 species # asymptote
03
Logging Impact Scenarios
Propagating uncertainty through policy
For each logging scenario (remove heights above a threshold), we compute the fraction of total abundance that would be lost — but with full uncertainty propagation.

Rather than computing one loss percentage from the observed counts, we draw 10,000 Poisson samples for all heights, compute loss in each draw, and summarise the distribution. The weighted biodiversity impact score combines all families, weighted by species richness so richer families count more.
# 10,000 times: total = rng.poisson(counts, size=N) # all heights lost = total[removed_heights].sum() pct_lost = lost / total.sum() × 100 # Weighted impact score: score = Σ (pct_lost[f] × species_weight[f])
04
Temporal Sensitivity Analysis
What if we sampled in a different season?
The two-week sampling window is the study's biggest limitation. We model seasonal variation as log-normal multiplicative noise applied to each observed count — log-normal because it's always positive and right-skewed, like real biological variation.

Three CV (coefficient of variation) assumptions bracket plausible seasonality: 15% (low), 30% (medium, literature-supported), and 50% (high). For each of 10,000 draws, we ask: does the qualitative conclusion still hold?
# Log-normal noise model: σ = sqrt(log(CV² + 1)) μ = −σ² / 2 # ensures E[noise] = 1 noise = rng.lognormal(μ, σ, size=(N, 5)) scaled = observed_counts × noise # Ask: is ground still the peak?
Distribution Choices — and Why
Distribution Used for Why appropriate Key parameter
Poisson Modules 1 & 3 — specimen counts Count data with no upper bound; mean = variance; natural model for random arrivals in traps over time λ = observed count per height
Log-normal Module 4 — seasonal noise Multiplicative biological variation is always positive and right-skewed; log-normal is the standard ecological choice for abundance variation CV ∈ {0.15, 0.30, 0.50}
Bernoulli (implicit) Module 2 — species detection Each species is either detected (1) or not (0) at each height; detection probability derived from observed richness ratio p = observed_species / total_species
Negative exponential saturation Module 2 — richness asymptote Species accumulation curves universally follow diminishing returns; fitted via nonlinear least squares to extrapolate beyond observed data S_max ≈ 858; κ ≈ 0.55

Module 04 · Temporal Sensitivity

Are two weeks enough?

Sampling occurred over a single two-week window. Log-normal noise with varying coefficients of variation simulates what would happen if the study were repeated in different seasons. How often would the same conclusions hold?

Diptera's ground-level dominance is highly robust. Lepidoptera's canopy preference is equally consistent — both findings survive seasonal uncertainty.
